# Antigravity UX Engine

A production-grade React frontend architecture featuring advanced animations, theming, and accessibility.

## Quick Start

```bash
# Install dependencies
npm ci

# Start development server
npm run dev

# Run unit tests
npm test

# Build for production
npm run build

# Preview production build
npm run preview
```

## Features

- **Strict TypeScript**: Type safety throughout.
- **Theming**: Light, Dark, and Cyber modes with persistence.
- **Animations**: Framer Motion for smooth interactions.
- **Accessibility**: WCAG AA compliant contrast and ARIA labels.
- **Components**: Modular, reusable UI primitives.

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- Vitest
